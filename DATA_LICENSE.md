# Data license

The dataset (39 egocentric work clips: stereo video, raw hand detections,
camera pose, timestamps and task metadata) is **not stored in this
repository**. It is archived on Zenodo, doi:10.5281/zenodo.23056146, and is
licensed under the **Creative Commons Attribution 4.0 International
(CC BY 4.0)** license: https://creativecommons.org/licenses/by/4.0/

If you use the data, please cite the paper (see `CITATION.cff`).

The videos show people at work and have **not** been face-blurred. Use the
data for research on egocentric perception only, and do not attempt to
identify any person shown.

The source code in this repository is licensed separately under the MIT
license (see `LICENSE`).
